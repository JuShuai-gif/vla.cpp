# vla.cpp + Piper 单臂接入验收（2026-11-04）

软件接入已在 skysi（aibox，M1000，Linux aarch64 6.6.10）完成，无真机。
基础代码：robot_runtime `6633aef`、vla.cpp `4a1d31a`；本报告与接入源码一同提交。
没有修改计算内核、GGUF 权重或低精度方案；没有执行机械臂动作。

## 已部署

- vla.cpp 公共 API：`inspect_policy/load_policy`，具名 RGB 相机、原始状态输入，输出反归一化的 50×7 动作。
- runtime 插件：`vla_cpp`；相机角色按各自 GGUF 顺序映射；两种预设 `pruned/full`，启动时选择。
- 本机配置：`configs/vla_piper.json`；策略：`configs/policies/vla_{pruned,full}.json`。
- Python 3.12.12 独立 `.venv`；Torch 2.6.0+cpu、NumPy 2.5.4、GGUF 0.19.0、tokenizers 0.23.3、sentencepiece 0.2.2、Pillow 12.3.0、OpenCV headless 4.13.0.92、python-can 4.6.1、draccus 0.11.6。
- V3 SDK `piper-sdk==0.7.0a1` 隔离在 `runtime/piper-v3`；内置 SDK 未替换。两个 SDK 导入通过。
- `runtime/can-tools` 提供 ethtool 5.16 和 can-utils 2020.11.0；`runtime/v4l-tools` 提供 v4l2-ctl 1.22.1。env.sh 已加入对应 PATH。
- `can/can_raw/can_dev/gs_usb/uvcvideo/usbserial/ch341/cdc_acm` 已有当前内核模块；SocketCAN socket 可打开/关闭，未绑定总线、未发送帧。

Python 官方预编译包下载过慢，改用 Python 3.12.12 官方源码的国内镜像，SHA-256 与官方 `.sigstore` 发布摘要相同：
`fb85a13414b028c49ba18bbd523c2d055a30b56b18b92ce454ea2c51edc656c4`。
源码配置前缀 `runtime/python312`；缺失的 SQLite/BZip2/LZMA/readline 开发包从已配置的 Ubuntu APT 仓库下载、解包到 `runtime/python-dev` 后构建，未改系统包。
板卡自带 SQLite 包为定制版本，项目内明确使用 Ubuntu `3.37.2-2ubuntu0.8` 的库与头文件，不覆盖系统 SQLite。
SSL、SQLite、ctypes、bz2、lzma、readline 均导入通过；未构建与本任务无关的 Tk/curses/gdbm 可选模块。
完整安装日志和源码归档在 `validation/cache/python*`，最终环境 freeze 在 `validation/vla_cpp/environment-freeze.txt`。

## 接真机前尚需现场完成

- 当前没有 CAN 接口或相机节点；设备绑定保持 null，不为已存在的四路秦恒串口猜测机器人身份。
- 当前用户已有 video/render 组；没有免密 sudo。本轮未更改 sudoers、用户组或 udev，实际驱动加载/接口激活按网页命令在终端进行。
- 内核没有 SLCAN；若实际 CAN 转接器使用 SLCAN 而非 gs_usb，需要另按型号适配。
- USB 相机当前准备的是通用 UVC 路径。RealSense SDK/专用 udev 规则未安装，接到 RealSense 时按环境文档处理。
- 未取得当前机械臂的标定；不能沿用仓库其他双臂的标定。
- 两模型都没有明确的训练单位元数据。`absolute_joint/degrees/mm` 是待核实的部署声明，`source_contract.verified=false`，live 执行被后端拒绝。
- 本机暂用离线验证提示词，需核实训练任务；本地 v2 数据集任务为 `Grab the block and put it in the basket`，其路径并不等于两个 checkpoint 的训练目录，不能据此确认两者任务或单位。
- `execute_robot=false/dry_run=true`；未做相机采集、真实 CAN 收发、闭环推理或运动验收。

操作步骤见 `docs/VLA_CPP.md`。硬件未插入时应使用资源检查和 robot-replay；`--check/--warmup-only/--dry-run` 需要先绑定真实设备。

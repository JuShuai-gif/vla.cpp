## 执行规则

1. 按编号推进；先提交清单，再开始实验。每项更新状态、结论及原始数据链接。
2. GPU 测试串行执行，不让两个实验争用设备。先核实 performance 模式。
3. 每项保留基线和实验开关；先微基准，再整模型，最后合并。性能退步或不稳定的方案不默认启用。
4. 不能改去噪步数、chunk50、相机顺序或 token 裁剪规则来获得不等价收益。
5. 记录精度/Graph/变输入失败；不得把接口存在当作目标形状可运行。
6. 不升级系统、不改驱动、不迁移到 MP31 专用 MATE；只在服务器归档和 Git 提交。

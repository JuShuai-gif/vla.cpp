## 复现

```bash
cd /home/skysi/code/vla.cpp
python3 scripts/patch_ggml_musa.py build-musa-deps/llama
cmake --build build-musa-official -j 8
ctest --test-dir build-musa-official --output-on-failure
```

run_io_matrix.py / run_layout_matrix.py / run_late_matrix.py / run_fold_abba.py / run_validation.py / run_comparison.py 保留实验顺序，拒绝覆盖已有 stage；复测需使用新记录目录/stage。GPU 实验串行，期间不修改实现或构建。

在本记录目录构建独立形状探针：

```bash
/usr/local/musa/bin/mcc -O3 -std=c++17 -x musa -mtgpu --cuda-gpu-arch=mp_22 -ffp-contract=off -I/usr/local/musa/include probe_gemm_shapes.cu -L/usr/local/musa/lib -lmusart -lmublas -Wl,-rpath,/usr/local/musa/lib -o /tmp/pi05-probe-gemm-shapes
```

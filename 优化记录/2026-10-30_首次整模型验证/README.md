# 首次整模型验证与耗时记录

测量日期：2026-10-30；补充归档：2026-11-02。

这是目前找到并可核验的最早一批两模型完整 CPU/MUSA 验证记录，早于后续正式优化基准。原始文件此前保存在每个模型的 `gguf/validation/`，现将 JSON 与日志一起归档。不能保证所有更早的临时试跑均留有记录。

## 最早整模型耗时

| 模型 | CPU ms | MUSA ms | MUSA/CPU 最大动作误差 |
| --- | ---: | ---: | ---: |
| 裁剪模型：15 层视觉、3 步 | 10866.356 | 2198.943 | 0.027464 |
| 完整模型：27 层视觉、10 步 | 22461.373 | 4560.177 | 0.038258 |

数值来自各模型 `cpu-f32-report.json`、`musa-f32-report.json` 的 `timing_ms.ms_total`，包含视觉与主推理，不包含模型加载。F32 驻留权重/F32 激活，固定合成输入，CPU 4 线程。它们是验证过程中记录的一次预测，**不是五次稳态 wall time 的中位数**。报告的 `elapsed_s` 是验证流程耗时，不是表中推理时延。

后来正式重复基准的 F32 中位数分别为 1844.533 / 4106.170 ms，详见 [后续优化阶段](../2026-10-30_M1000首轮优化/README.md)。两套测量口径不同，不拼接成同一次严格 A/B 实验。

## 证据文件

每个模型目录保留 CPU/MUSA 原始报告和运行配置、对应日志、视觉参考日志、误差比较，以及完整推理入口的 JSON/日志。`manifest.json` 记录来源与 SHA-256。

原始图像、NPY 动作、NPZ 视觉参考等二进制文件仍保存在 manifest 所指向的源目录，未加入 Git。本次只整理历史记录，没有重新执行模型测试。

这批记录完成了合成 CPU/MUSA、独立视觉参考和完整入口数值检查，不代表原始 Python 完整策略对照或真实机器人任务验收。

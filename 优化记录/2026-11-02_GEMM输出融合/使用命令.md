# 使用命令

沿用现有两种 checkpoint 布局的 GGUF 和推理脚本。此优化显式开启，默认不变。

    cd /home/skysi/code/vla.cpp
    export VLA_LIBRARY=$PWD/build-musa-official/libvla.so
    export VLA_DEVICE=0 VLA_N_THREADS=4
    export VLA_MUSA_VISION_SDPA=1 VLA_PI05_VISION_QKV=1
    export VLA_MUSA_VISION_EPILOGUE=all
    unset VLA_PI05_INPUT_CACHE

剪枝模型 pi05_cube_merge_cksize50_step3_0929：

    export VLA_MUSA_GEMMA_ATTN=fused-denoise

完整模型 cup_cube_joint_061_a800_50k_20261022：

    export VLA_MUSA_GEMMA_ATTN=fused-all

然后使用 scripts/run_pi05.py 的各自图片、文本和状态参数，并保留：

    --weight-dtype f16 --act-dtype f32 --flash-attn --warmup 3

在进程初始化前设置选项。同进程加载两模型可统一使用 fused-denoise，但完整模型达不到表中独立进程 fused-all 的性能。新 epilogue=all 可共同使用。

回退本轮：unset VLA_MUSA_VISION_EPILOGUE。gelu / residual 是单项对比模式，最终推荐 all。其他后端不受此 MUSA 开关影响。

构建沿用 scripts/build_musa.sh；当前视觉 SDPA 需要 -DVLA_MUSA_MUDNN_ATTN=ON，新 epilogue 没有新增库依赖。

run_validation.py、run_comparison.py、summarize.py 提供复现命令，会拒绝覆盖既有结果目录；重跑前先归档或在优化记录下复制到新的同层目录。check_entry_reuse.py 复核完整入口与上轮一致。run_lt.py 为独立微基准。早期源码已变更，不能用最终代码开关假装重现 03_短测.md 的历史结果；对应源码差异与编译探索已保留。

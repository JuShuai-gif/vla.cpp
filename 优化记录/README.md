## 后续记录约定

- 每轮建立 `YYYY-MM-DD_中文主题/` 子目录，目录内用 `README.md` 说明方案、结论和原始数据位置；原始工具输出保留原文件名。
- 每个可测量阶段记录改动方案、基线与优化后延迟、测试次数、预热条件、输入形状、模型配置、精度和参考误差。
- 记录硬件、驱动/SDK、电源模式、命令和对应代码版本。无法取得的字段写明“未记录”，不推测补填。
- 合并测量的改动明确标注，失败、退步和撤回的方案也保留。不能用最终代码的开关假装重现已不存在的历史版本。
- 区分历史结果、本轮复测、计划和已实施内容；GPU 跳过测试不能写成 GPU 验证通过。
- 原始 JSON、运行配置和必要日志随 Git 保存；模型权重、构建产物等大文件保留外部路径与必要校验信息。
- 完成一轮后更新本索引，并将记录与对应代码一起提交。

仓库内记录是主版本。按用户最新要求，后续记录只在服务器归档并提交 Git，不自动同步到 Mac。
